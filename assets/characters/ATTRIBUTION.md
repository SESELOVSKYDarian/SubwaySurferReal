# Runner

`runner.glb` is the Vanguard/Soldier character and skeletal animations from
Adobe Mixamo, distributed in the official Three.js r160 skinning example.
The binary is included unchanged.

- Source: https://github.com/mrdoob/three.js/blob/r160/examples/models/gltf/Soldier.glb
- Original provider: https://www.mixamo.com/
- Example: https://threejs.org/examples/#webgl_animation_skinning_blending
- Usage guidance: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

Adobe's Mixamo FAQ permits royalty-free use of characters and animations in
personal, commercial and nonprofit projects, including video games. This file
is supplied as a component of this game. The Three.js MIT license applies to
the engine in `vendor/three`, and is not asserted as the license of this model.

The officer uses an independently cloned skeleton of the same unchanged binary,
with a runtime navy uniform shader and game-authored police equipment and labels.
No separate police model is claimed. Three.js SkeletonUtils and
RoundedBoxGeometry retain the engine's MIT license in `vendor/three/LICENSE`.
