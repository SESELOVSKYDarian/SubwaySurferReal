# Current technical-school character

`technical-student.glb` is generated by `tools/build_student.py` using the MakeHuman
CC0 anatomical base and game-authored clothing, hair additions, rig and poses.
The blue work coat is inspired by the supplied wardrobe reference. No exact
portrait likeness is claimed. The teacher now uses separate photo-inspired
`professor-police.glb` and `professor-police-low.glb` models described below.

- Asset license: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md
- The OBJ header explicitly records its CC0 release in September 2020.
- Listed rights holders: Data Collection AB; Joel Palmius; Jonas Hauquier.
- Included source: `source/makehuman-base.obj.gz`.
- Included license: `source/MAKEHUMAN-CC0.md`.

Covered torso/upper-thigh geometry and helpers are omitted from the rendered
anatomy. The coat, lapels, pockets, buttons, shoes, additional hair, material setup,
19-bone skin and runtime poses are authored for this game. The mesh needs no
Mixamo animation or soldier geometry. Material geometry is batched when possible.

## Legacy cached character

The unused `runner.glb` remains for older cached releases. It is the unchanged
Vanguard/Soldier character distributed by Three.js r160, originally from Adobe
Mixamo. It is not loaded by the current character module.

- Source: https://github.com/mrdoob/three.js/blob/r160/examples/models/gltf/Soldier.glb
- Provider: https://www.mixamo.com/
- Usage: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

Mixamo's FAQ permits royalty-free use within video games. No MIT license is
asserted for that legacy model. The Three.js engine, GLTFLoader, SkeletonUtils
and RoundedBoxGeometry retain their MIT license in `vendor/three/LICENSE`.

## Marplatense detail revision

The high-detail model refines exposed skin with one authored Catmull-Clark style
pass and uses 64 coat contour segments; the low-detail model keeps the original
skin topology. Both are reproducible with `tools/build_student.py` (add `--low`
for the low version), retain the same 19-bone rig and use the CC0 source above.
The initial generic teacher variation has been superseded by the separate
photo-inspired professor profile described below. School furniture, bus liveries and painted wall lettering are
procedural game artwork based on the requested references.


## Photo-inspired professor with police cap

`professor-police.glb` and `professor-police-low.glb` use the same CC0 anatomical
source above, with separately authored body/head proportions, olive crew-neck
sweater, dark trousers, brown boots, rectangular spectacles, gray beard and
mustache, wristwatch, and a peaked police cap with generic raised shield.
The four user-provided photographs were used as visual references. They are not
embedded in the GLBs or distributed as image files. This is a modeled likeness
approximation, not a photographic face scan or exact identity reconstruction.

Build: `python3 tools/build_student.py --professor` (add `--low` for the low model).
Additional authored geometry is in `tools/professor_details.py`; the beard's
procedural color/alpha texture is generated locally by `character.js`.
No additional downloaded model, brand badge or external texture is used.

## Realism materials work branch

The work branch adds CC0 MakeHuman system assets: old light-skinned male skin,
brown eyes, short02 hair, shoes01 footwear, adult-age/weight targets and the
standard body weights. This is a generic skin reference, not the professor's
photographic facial texture. Source headers retain the rights holders and CC0
notices. Exact source paths, archive URL and SHA-256 hashes are recorded in
`source/realism/SOURCES.json`; the CC0 text remains in `source/MAKEHUMAN-CC0.md`.

Skin micro-normal and roughness maps are authored approximations derived from
the reference albedo. Hair is desaturated to gray; footwear and eye derivatives
preserve their UV layout and required alpha. Preparation code is included in
`tools/prepare_professor_textures.py`. No AGPL MakeHuman program code is copied;
the geometry/UV/weight processing code is authored for this project.

## Edición en Blender

`blender/professor.blend` contiene las mallas CC0 anteriores editadas con Blender
4.3.2 y sus materiales empaquetados. La textura de barba `professor-beard.png`
y el cuello de punto se generaron para este proyecto. El archivo no contiene
fotografías originales del profesor ni una textura presentada como su rostro real.
