# Skills de modelado 3D instaladas

Copiadas sin cambios desde GitHub (licencia MIT, incluida en cada carpeta) para
la reconstrucción de Estanga. No se copian evaluaciones ni recursos de ejemplo.

| Skills | Repositorio |
| --- | --- |
| reference-to-3d, orthographic-registration, multiview-fit-loop, texture-driven-mesh-fitting, reference-look-calibration, animation-quality-gate, blender-modeling, blender-export, blender-animation, blender-materials, blender-uv-texturing, text-to-blender | https://github.com/roble3/cc-blender-skill |
| threejs-animation, threejs-loaders, threejs-materials | https://github.com/cloudai-x/threejs-skills |
| blender-web-pipeline | https://github.com/freshtechbro/claudedesignskills |

Varias asumen un servidor MCP de Blender. En este proyecto se aplicaron sus
métodos (registro ortográfico, ajuste multivista con IoU, ajuste de malla a la
textura, calibración de aspecto, hoja de contactos de animación y exportación
glTF) con Blender en modo `-b` y scripts propios: ver `docs/estanga.md`.
